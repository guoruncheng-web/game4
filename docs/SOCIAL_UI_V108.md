## 对照依据与设计选择

当前官方 APK 仍为 `com.wepie.weplay` 5.26.31.2 / 10264，SHA256
`da19b860b410f2baac55af96ad7709422e1c2d9918a2561360dd94893c58a3d3`。
REA/JADX 的证据范围及加载器/业务控制器恢复限制见 `SOCIAL_UI_V107.md`。

- `activity_add_friend`：44px 顶栏、16 标题、40 搜索、左右16、8圆角，显示本人 ID。
- `voice_room_msg_send_view`：16 正文、38 最小输入、最多四行、50 发送触区。
  `shape_ececec_corner8` 实际是白色填充、`#e6e7ec` 细边和8圆角，未误按文件名画灰底。
- `room_bottom_util_item_view`：64 单元宽、48 图、12 标签、4 图文距；工具面板深灰。
- `voice_room_title_view`：24px 在线胶囊、6px 绿点、10px 白字；点击打开成员为 PWA 既有数据的交互适配。
- `cp_room_view` 明确使用 `cp_room_bg.webp`，本轮选择它作为 PWA 房间主题。
  **这不是对普通房默认主题的认定**；普通房 `RoomThemeBgView` 仍由运行时决定。
- 账号详情借用已核对的共用尺寸，未把未成年模式四位 PIN 布局误当账号改密。
- 私聊气泡色、五分钟时间分组及成员72/44/16行，是保留现有功能后的布局适配；
  动态原生皮肤与实际成员行绑定仍需登录后的 App 画面确认。

新增七个泛用图片的原始路径、用途和 SHA256 见
`design/social-v108/reference-assets.json`。游戏插画沿用原始 imagegen 资产，
不会把这些 APK 图片写作原创，也没有导入会玩名称、登录协议或无后端的付费功能。

## 验证与曾发现的问题

结果入口：`evidence/social-v108/VALIDATION.json`、`browser/result.json`、
`offline/result.json`、构建/ESLint日志及缓存版本测试。浏览器使用 loopback
夹具；新增好友、拒绝申请、消息写入都是夹具数据，不是生产账号操作。
头像只测试选图预览和取消，没有上传；未执行真实改密、注册或 RTC。

首次鼠标驱动在返回私聊后过早点击仍隐藏的导航，保留失败记录；修正为等待目标
可见后点击。截图复核还发现更多工具的白字被旧选择器留在白底上，修正选择器
优先级并加入实际文字/底色对比度检查。两类失败均保留在 `first-attempt-*`。

手机键盘适配通过可视高度缩小的浏览器检查；这不是 Mac 模拟器真键盘或
iOS/Android 原生 App 真机键盘验收。PWA 真实语音与游戏玩法不记为本轮通过。
