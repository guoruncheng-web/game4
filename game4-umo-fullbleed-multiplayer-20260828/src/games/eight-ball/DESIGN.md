# Eight Ball 设计说明

面向海外休闲玩家的竖屏 8 球对战。界面全英文,玩法用最通行的酒吧规则(bar rules),
上手不需要读规则说明 —— 会点手机的人都知道桌球怎么打。

## 核心循环

摆球 → 瞄准(拖台面) → 定力度(拖底部力度条)→ 松手出杆 → 看球滚 → 判定 → 换手/续杆 → 打进黑八结束。
单局 20~25 杆(自己这一侧),约 3~5 分钟,正好是一段通勤时间。

## 规则(实现在 `rules.ts`)

- 开球:母球放在开球线以下的区域内,由玩家自己挑位置。开球后台面保持「未定组」。
- 定组:开球之后的第一次合法进球才决定全色/花色,按第一颗进袋的球算。
- 犯规(一律罚对手自由球,可放全台):
  - 母球落袋;
  - 空杆(一颗球都没碰到);
  - 先碰的不是自己那组(未定组时先碰黑八也算);
  - 碰到球之后,既没有球进袋也没有任何球碰库。
- 黑八:自己那组清完才能打。提前打进、或者连同犯规打进,都是直接判负;合法打进即胜。
- 开球把黑八打进:摆回台面继续打,不奖不罚(而不是判负 —— 开局就输太劝退)。

**刻意没做的**:击球线后放球的细则、指定袋、加塞(english)、跳球、推杆。
这些都是把休闲玩家挡在门外的东西,真要加也是等留存数据说话之后。

## 难度(`config.ts` 的 DIFFICULTIES)

AI 的强弱**不靠改规则、也不靠让它选错球**,而是给最终出杆加瞄准误差和力度误差。
这样低难度 AI 表现出来的是"选对了球但打偏了",输给它不会觉得被戏弄。

| | 瞄准误差 | 力度误差 | 试算候选 |
| --- | --- | --- | --- |
| ROOKIE | ±0.045 rad | ±22% | 4 |
| PRO | ±0.018 rad | ±12% | 8 |
| SHARK | ±0.006 rad | ±5% | 14 |

无头自对弈 40 局验证过的档位区分度(先开球方在前):

```
rookie vs pro    →  7 : 33
pro    vs shark  →  5 : 35
pro    vs pro    → 17 : 23      同档接近五五开
shark  vs shark  → 22 : 18
```

## 手感旋钮(`config.ts` 的 PHYSICS)

- `friction` 台面摩擦。调大 = 球跑不远、走位保守;调小 = 满台乱窜。
- `cushionRestitution` 撞库能量保留。0.72 大致对应真实台的手感,调到 0.9 会像弹珠台。
- `maxShotSpeed` 满力初速度。它决定开球能不能把球堆炸开。
- `stopSpeed` 静止阈值。调小会让回合尾巴拖很久(球在肉眼看不见地蠕动),调大则会出现"球还在动就被判停"。

## 分层

```
physics.ts    纯数学:球、库、袋、碰撞、静止判定。不 import 任何引擎
rules.ts      纯逻辑:一杆的事实 → 犯规/续杆/定组/胜负
ai.ts         几何粗筛 + 用 physics 无头试算,挑分最高的一杆
table.ts      摆球
--- 以上不依赖 Phaser,换渲染引擎(比如 Three.js)时一行都不用动 ---
textures.ts   Canvas 现场生成球/球杆贴图
table-view.ts 台面静态绘制
scenes/       Boot / Menu / Game / GameOver
```

这条分界线是刻意画的:桌球最难的部分是物理和 AI,它们不该和渲染绑死。

## 已知取舍

- 没有加塞和杆法,母球撞击后按纯弹性走位。休闲玩家不吃这一块,但硬核玩家会觉得走位单调。
- 袋口判定是"圆形捕获区",不模拟袋角的真实几何,所以极限贴库球比真台略容易进。
- AI 只做单杆最优 + 一步走位评估,不做多杆布局(职业选手那种连续清台的思路)。
