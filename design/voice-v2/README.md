# 语音房 v2 设计与验收

2026-09-10。语音房主页面已改为“轻量语音客厅”布局，创建语音房仍不要求关联游戏。

## 页面结构

- 顶部固定显示房名、可见性、房间码及房间操作。
- 在线人数和连接状态使用图形加文字表达。
- 八个麦位是页面主内容，房主、禁麦和空位状态保持真实。
- 成员入口、邀请好友和房间聊天分别成区。
- 麦克风、离开房间和消息输入整合为底部操作台。
- 管理页、邀请面板和离开确认使用同一奶白、绿色与珊瑚红视觉。
