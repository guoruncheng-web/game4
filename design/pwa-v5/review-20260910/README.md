## 未通过与证据边界

- 注册原稿的自填账号密码与现行自动 UID 后设置密码协议不同；成功页不展示不存在的随机密码。此差异未标为一比一通过。
- 管理页尚缺管理员真实实拍；现行统计含义与原稿不同。
- 语音房 RTC、真实麦克风权限、音轨生命周期和 RTC 重连未完成；页面明确显示语音尚未连接。
- 加载页重复宿主返回键已在源码隐藏，但修复后瞬态截图超时。15-loading-final.png 为保留的修复前实拍，名称不代表最终验收；失败记录见 loading-screenshot-retry.json。
- 叠叠乐横屏底部托盘有裁切，尚未修改游戏内部布局。3D 游戏未做完整玩法与低端设备性能验收。
- 离线页面可达不等于 Service Worker 真实断网缓存通过；本轮未重做 PWA 离线、音频和公网协议验收。
- 未覆盖 iOS/Safari、Android 真机、系统键盘、安装态 PWA、最低配置设备及跨地区网络。
- 保留已有 Next middleware → proxy 弃用警告。3314 上 POST/WS Origin 被拒是预览端口限制，后续功能测试使用 3000，未放宽网关。

## 工作区与回滚边界

本轮仅修改当前工作区，未提交、推送或部署，未替换生产游戏树，因此没有本轮发布回滚提交或旧树备份。工作区原本已有多项改动，不能用整库 reset 回滚。撤销应逐项审阅本轮组件/CSS/资源 diff，并保留用户原有改动。历史验收文档备份在 prior-acceptance.md；生产发布回滚仍按 ../../../../deploy/README.md 执行。
