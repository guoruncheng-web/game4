# 趣宝玩 · 夜游俱乐部 v1

Owner 在四套主题对照之后选定：「夜游俱乐部」。本轮实现仅面向个人 PWA，仓库为 `guoruncheng-web/game4`，基于已发布 v104 的源码及发布回执提交 `d97ce60391f27401ffd6818273ee92b8a75bcade`。游戏仓库拆分 PR 是独立事项，本分支不合并该分支，不修改公司游戏、宿主或 CDN。

## 视觉规范

- 背景 `#121826`；表面 `#1B2536`；抬升表面 `#243044`；边线 `#303D52`。
- 正文 `#F2F5FB`；次级文字 `#A5B3C8`；薄荷强调 `#75E3C7`；强调色上文字 `#12352D`。
- 警告 `#EDCB8C`；错误与危险操作 `#FF9CAA`。错误同时提供文字，不仅依赖颜色。
- 统一 10–17px 控件圆角、44px 左右触控目标、16px 表单文字。中文使用系统字体，拉丁文字沿用项目已有 Geist。
- 首页以紧凑品牌栏、语音房入口、分类游戏库组织；封面为哑光纸感插画，名称与状态全部用 DOM 渲染。保留游戏维护状态和原来的鉴权入口。
- 麦位按服务端数量显示，未改动入座、审批、禁麦、RTC 或游戏权限。仅更换外层页面与控件表现。
- 消息、资料、头像、密码、创建房间、邀请、管理、确认、离线和启动准备使用同一套颜色与间距；删除旧的截图定位和多层皮肤入口。
- 选择主题不改变注册状态，内测账号登录继续生效。

## 资源来源与用途

`public/assets/nightclub/game-covers-v1.webp`：内置 `image_gen` 生成的 3 列 × 4 行游戏封面图集，由原图进行无裁切 WebP 压缩；原图保存在本目录 `game-covers-source.png`。实际输出为 1254 × 1254，CSS 按等分网格取图。图集不含名称、按钮文案或账号资料，不增加未开放游戏的入口。

顺序（从左至右、从上至下）：南方十三张、UMO、飞行棋、台球、水果、叠叠消、星际跑酷、霓虹突击 2D、霓虹突击、捕鱼、备用麻将图、Thirteen Social。备用图不对应新增玩法。用途为首页、邀请卡和房间游戏入口的装饰封面。

生成提示词：成熟的休闲社交游戏俱乐部封面图集，深蓝 App 外壳与薄荷色强调；精确 3×4 等分，无间隔、无边框、无圆角、无文字或数字；每格中央 60% 放置单一游戏静物，保留负空间；平面编辑插画、轻纸纹、切纸层次和哑光材质；低饱和青绿、海军蓝、陶土、沙色、灰紫、薄荷与象牙白。按上述顺序表现扑克牌、彩色卡片、飞行棋、无数字台球、水果切片、拼图块与蘑菇、平台跳跃机器人、俯视战机、科幻战机、游鱼、竹纹麻将、四人围桌牌局。避免高光玩具、儿童吉祥物、赌场奢华、金币、标志、水印与设备展示。

`public/assets/nightclub/icons-v1.png`：项目已安装 Lucide 图标的 4×4 PNG 遮罩图集；由 `node tools/pwa/build-nightclub-icons.mjs` 重建，需已有 Python CairoSVG。沿用既有图标库，运行时使用 PNG，以 currentColor 着色；可编辑 SVG 源保存在 `icons-source.svg`，保留 Lucide 原有许可。没有安装项目依赖。

## 工程与验收范围

公共样式唯一入口为 `src/app/nightclub.css`；`globals.css` 只保留 Tailwind 和基础样式。旧 v5、auth-v2、voice-layout、voice-reference、voice-room-v2、pwa-prepare CSS 从运行入口删除，历史设计与原资源保留在 Git 历史中。

缓存版本升为 v105，并同步工作流中的版本断言；新封面与 PNG 图标进入外壳预缓存。现有工作流仍指向旧服务器，禁止通过合并 main 触发部署，本次不发布 UI 到生产。

浏览器夹具只监听 loopback，用于真实组件的布局和交互验收，不签发真实会话、RTC 票据，也不连接真实数据库。截图中的人物、余额和房间属于示例数据；真实鉴权和 RTC 不计为本次通过。初次验收的程序点击焦点、未重置消息夹具与开发路由冷编译超时分别保留失败记录，最终生产包结果单独记录。
